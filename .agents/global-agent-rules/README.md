# Правила разработки игры

Локальная адаптация комплекта из пользовательского архива
`global-agents-rules (2).zip` для проекта «Тінь Забутого Королівства».
Этот каталог — рабочая копия правил проекта; исходный архив не изменяется.

## Состав и применение

- [Корневой AGENTS.md](../../AGENTS.md) — точка входа, факты этой игры,
  локальные уточнения и порядок развития инструкций.
- [AGENTS.md](AGENTS.md) — общий процесс разработки и проверки Unity-проектов.
- [code-style.md](code-style.md) — стиль C# при отсутствии более конкретных
  соглашений в коде или настройках форматирования.
- [Пайплайн UI Toolkit](pipelines/unity-ui-toolkit-interface-pipeline.md) —
  разработка игровых интерфейсов с согласованием финального HTML и версии
  в Unity; добавлен из отдельного пользовательского документа.

Перед работой читать корневой файл, затем общие правила и, для C#, стиль кода.
Сначала изучать проект, не добавлять пакеты и архитектуру заранее, сохранять
сериализованные данные, проверять изменённое поведение и честно указывать
недоступные проверки. Приоритет инструкций определён в корневом `AGENTS.md`.

## Особенности исходного архива

В архиве находятся **три содержательных файла**: `AGENTS.md`, `code-style.md`
и `README.md`. Служебные записи macOS исключены при импорте.

Исходный README описывал более полный комплект: pipeline-инструкции, шаблоны,
устанавливаемый skill и служебные скрипты. Этих файлов в архиве нет; они не
требуются для применения текущих правил. Ссылки и команды, предполагающие их
наличие, удалены из рабочих инструкций. Путь `F:\VIBECODE` относился к другой
машине и не используется. Подмодуль и глобальный skill не устанавливались.

SHA-256 исходного архива:
`C7261C60E12BD80B5244E5A2B1B5A9DB2DFAEDBDD36596DE17DB9645FD2C523E`.

## Развитие правил

Пользователь разрешил дорабатывать инструкции по мере разработки игры.
Факты проекта и решения записывать в корневом файле или соответствующем
существующем документе игры; универсальные правила — здесь, стиль — в
`code-style.md`. Добавлять подтверждённые, полезные повторно выводы,
объединять дубли и удалять устаревшее. Изменение правил не подменяет
согласование существенных решений о самой игре.

## Существенные изменения

- **2026-09-20:** по отдельному запросу пользователя подключён UI Toolkit
  pipeline версии `0.2-project.1`. Сохранены два согласования, исключены
  требования к механикам другой игры; уточнены язык UI, хранение прототипов
  и использование доступных инструментов. Выбор UI Toolkit записан в корневых
  правилах; подключение документа само по себе не создаёт игровые экраны.

- **2026-09-20:** подключены правила в корневом `AGENTS.md` и зафиксирован
  обнаруженный Unity-стек. Убраны зависимости от отсутствующих файлов и чужой
  машины. Процентные пороги уверенности заменены проверкой конкретных
  нерешённых вопросов; необходимые обратимые шаги в рамках порученной задачи
  не требуют повторного разрешения. Проверки документации отделены от проверок
  игрового поведения. Запрещено открывать второй Editor на занятом проекте
  ради автоматизации. Стиль C# сохранён без изменений.
