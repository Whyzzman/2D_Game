## 2. Розкладка HUD

**Центр екрана належить бою.** Нічого туди не заходить.

| Кут | Що там |
| --- | --- |
| ліворуч знизу | здоров'я, мана, витривалість |
| праворуч знизу | зброя, два уміння, три закляття |
| ліворуч зверху | стани й бафи |
| праворуч зверху | сповіщення |
| зверху по центру | смуга боса |
| над гравцем | підказка взаємодії |

Розмір смуги = її важливість: здоров'я 34 px, мана 18 px (82 % ширини),
витривалість 13 px (70 % ширини).

## 3. Типографіка

Шрифти (рішення Claude за постійною згодою, 2026-10-19): акцидентний — **Cormorant SC**,
основний — **Alegreya Sans**. Обидва під OFL і мають кирилицю; Cinzel кирилиці не має, тому гра
досі показувала Georgia. Розміри нижче не змінились.

| Роль | Розмір | Шрифт |
| --- | --- | --- |
| Ім'я боса | 34 px | акцидентний |
| Заголовок екрана | 28 px | акцидентний |
| Назва предмета | 20 px | акцидентний |
| Опис, кнопки | 17 px | гротеск |
| Характеристики | 15 px | гротеск |
| Підписи слотів | 13 px | гротеск |

**13 px — абсолютний мінімум** і лише для підписів слотів. Акцидентним шрифтом
абзаци не набираються.

## 4. Стан читається без кольору

Це правило доступності й воно не обговорюється:

| Стан | Ознака, крім кольору |
| --- | --- |
| порожній слот | пунктирна рамка + ромб усередині |
| екіпіровано | ромб у куті |
| унікальний | подвійна рамка |
| відкат | радіальне затемнення + число |
| дельта вгору/вниз | ▲ / ▼ перед числом |
| виконана передумова | суцільна лінія проти пунктирної |
| фокус | світло + зміна кольору канта одночасно |

## 5. Форма гілок умінь

Вузол має форму своєї гілки, тож дерево впізнається навіть монохромним:
**Воїн** — шестикутник, **Мисливець** — ромб, **Маг** — коло,
**Тінь** — надламаний многокутник.

## 6. Відмова пояснює себе

Недоступна дія **ніколи не мовчить**. Кнопка вимкнена, і поруч написано, чого
бракує: «Не вистачає Сили: потрібно 16, у вас 12».

## 7. Навігація

| Ввід | Правило |
| --- | --- |
| Esc у грі | пауза |
| Esc у паузі | закрити |
| Esc у підекрані | на рівень назад |
| модальне вікно | забирає ввід повністю; меню під ним не реагує |

Кожен екран має рядок підказок унизу з гліфами клавіатури й геймпада.
Підказки **не пишуть «натисніть E» текстом** — гліф приходить із системи вводу.

## 8. Локалізація

Макет розрахований на довший український текст: кнопки тягнуться, описи
переносяться, нічого не обрізається. У прототипі це видно на кнопці
«Порівняти з другим слотом», яка свідомо переноситься у два рядки.

## 9. Роздільність

Сцена 1920×1080, масштабується цілком. Клавіша **A** на будь-якому екрані
перемикає 16:9 / 16:10 — обидва оголошені цільовими, обидва перевірені.

## 10. Доступність

Реалізовано **в коді**, не лише в макеті (`GameSettings`):

| Налаштування | Дія |
| --- | --- |
| Тремтіння камери | 0 % вимикає повністю |
| Яскравість спалахів | 0 % вимикає повністю |
| Сила зупинки кадру | 0 % вимикає повністю |
| Числа шкоди | перемикач |

Бій лишається повністю читабельним із усіма трьома в нулі — це перевіряється
тестом із PHASE 20, а не обіцянкою.

**Налаштування зберігаються окремо від прогресу**
(`forgotten-kingdom.settings.json`). Нова гра стирає проходження й **не чіпає**
налаштування: втратити потрібні комусь опції доступності через перезапуск
кампанії неприпустимо. Це тримає тест `DeletingTheSaveDoesNotTouchTheSettings`.

## 11. Перенесення в Unity

UXML/USS — `Assets/Game/UI/` (тема `GameTheme.tss`, `GamePanelSettings`), код —
`Assets/Game/Runtime/UI/`. Пауза, інвентар, карта й інші вікна живуть у документі HUD і
ділять один простір USS-класів — новий екран бере власний префікс. Поведінка лишається в
ігрових службах (`InventoryScreen`, `WorldMapScreen`, `ShrineMenu`), вигляд лише читає їх.
Новий екран — спершу HTML на погодження, потім перенесення й порівняння з HTML поруч.

## 12. Меню: живий фон, переходи, фокус (2026-10-19)

Макет `design/ui/menus/menus.html` — інтерактивний (клавіші 1–7 — стани, M — «зменшений рух»,
стрілки / Enter / Esc — як у грі). Рішення Claude за постійною згодою:

- **Живий фон.** Титул — зала Гробниці: розетка вгорі, м'які промені, два ряди стрілчастих арок
  у тумані, вівтар із полум'ям унизу, пил у променях, жарини над вогнем; камера повільно «дихає»
  і злегка відповідає миші. У грі це справжня сцена `MainMenu`, макет лише задає настрій.
  Пауза — кадр гри **завмирає** й відступає: розмиття 7 px, яскравість 46 %, насиченість 62 %,
  масштаб 1,03, за 0,7 с.
- **Переходи.** Екран заходить знизу на 14 px із розмиттям 4 px → 0 за 0,52 с; пункти
  з'являються по черзі через 45 мс. Модальне вікно виростає з 96 %. Титул під налаштуваннями
  гасне до 18 %, а не зникає. Вихід у гру й на титул — завіса 0,9 с; вступ — 2,2 с (як у грі).
  Криві: `cubic-bezier(.22,.8,.26,1)` (вихід) і `(.65,0,.35,1)` (туди-назад).
- **Фокус** — світло й форма одночасно (§4): слово стає яскраво-золотим і розходиться на
  0,05 em, обабіч розходяться золоті нитки, за пунктом ковзає тепла пляма, ліворуч — полум'я
  корони, що ковзає до нового пункту за 0,32 с. Небезпечний пункт — те саме червоним.
  Вимкнений «Продовжити» лишається видимим з підписом «Збереження немає» і пропускається.
- **Налаштування** — одна панель без вкладок: «Звук» (загальна, музика, ефекти) і «Екран і
  доступність» (тремтіння, спалахи, зупинка при ударі, ефекти зображення). Під рядками —
  пояснення до рядка у фокусі. Повзунок тремтіння й спалахів **показує свою силу** на фоні,
  коли його рухають: гравець бачить, що вимикає. Нуль пишеться «Вимк.».
- Пункти меню — текстом без коробок, як у HK; панелі — лише для паузи, налаштувань і
  модального вікна, з ромбами в кутах (орнамент лише в кутах, `VISUAL_BIBLE` §15).

**Перенесення в Unity** (гілка `cloud/menus`, чекає локальної перевірки):

| Макет | Unity |
| --- | --- |
| живий фон титулу | справжня сцена `MainMenu` (туман, жарини, промені вже є) + `MenuCameraDrift`: дрейф ±0,14 / ±0,06 од. і нахил від миші ±0,18 / ±0,08 од., згладжено |
| розмиття гри під паузою | USS не має розмиття: затемнення 72 % з'являється за 0,32 с |
| переходи | `MenuMotion` + клас `motion` (Options.uss): 14 px і 0,52 с, рядки — 10 px і 0,42 с через 45 мс |
| світло фокусу | `MenuFocus`: овал із 12 еліпсів, полум'я й нитки — криві `Painter2D`, без спрайтів |
| попередній перегляд | `OptionsPanel`: меню труситься до 10 px, спалах до 0,35 і згасає за 0,12 с — лише UI, камера й `CombatFeedbackService` не чіпаються |
| шрифти | `Resources/Fonts` (OFL-ліцензії поруч), `HudFonts` бере їх першими, системні — відкат |

## 13. Відомі обмеження

- **Іконки намальовані як inline SVG** у прототипі. Вони представляють предмет
  візуально, як вимагає пайплайн, але це не фінальний набір іконок.
- **Шрифти** (з 2026-10-19): Cormorant SC + Alegreya Sans, обидва OFL; у грі — після
  перенесення меню (гілка `cloud/menus`), до того — системні Georgia / Arial.
- **Екрана завантаження немає** — переходи в зрізі миттєві (п. 137 брифу
  дозволяє не додавати).
- **Системи навчання немає** і ця фаза її не додавала (п. 140).
- **Перепризначення клавіш** — з 2026-09-27 (п. 41 плану): екран «Керування»
  (`design/ui/controls/controls.html`, `ControlsPanel`), прив'язки — у налаштуваннях.
- **Числа шкоди** показані як стиль, але системи damage numbers у грі немає:
  її створення було б новою механікою, а не UI-пасом.
- **Ручної перевірки на геймпаді не було** — потрібен пристрій і гра.
