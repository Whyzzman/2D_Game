# Слияние облачных веток и полный плейтест (п. 1 списка «уровень Hollow Knight»)

Составлено 2026-10-19 в облачной сессии, **решено Claude по постоянному согласию пользователя**. Сам п. 1
(собрать, пройти игру, починить подвисания) без Unity не выполнить: в облаке нет компилятора, тестов и
сборки. Что сделано в облаке — подготовка, чтобы локальная сессия начала сразу с проверки, а не со слияния.

## 1. Ветка `cloud/integration`

Все облачные ветки на 2026-10-19 слиты в одну ветку от `main` — **18 веток** в таком порядке:

`zone-marsh` → `surfaces` → `mana-wisp` → `boss-death` → `menus` → `player-anim` → `movement` → `camera-look`
→ `combat-feel` → `hit-pitch` → `haptics` → `audio` → `music` → `ambience` → `hud` → `world-react` → `hero-death`
→ `hitch-probe`.

Конфликты и как решены (текстом, без компиляции):

| Файл | Ветки | Решение |
| --- | --- | --- |
| `gamedesign/DEVELOPMENT_PLAN.md` | все, кроме чистых | взята таблица из `main`: в ней уже все ветки |
| `AudioId.cs` | `surfaces`, `audio`, `world-react`, `hero-death` | хвосты друг за другом: `FootstepWood…Ash`, `FootstepScuff`, `WallJumpKick`, `PropBreak`, `HeroFall`, `AltarCall` (порядок в веточных ассетах не важен — генератор пересобирает) |
| `PlaceholderAudioArt.cs`, `ContentBuilderAudio.cs` | те же | все `Spec` и `Sound` подряд, запятые дописаны |
| `CombatAudioBinder.cs` | `boss-death` × `hit-pitch` | смерть босса: удар сразу, крик позже; все остальные звуки — с высотой серии `_streak.PitchFor` |
| `CombatFeedbackService.cs` | `boss-death` × `haptics` | оба набора полей, свойств, `OnDisable`, `LateUpdate`; `OnApplicationFocus` от `haptics` |
| `HudController.cs` | `mana-wisp` × `hud` | искры маны остаются; фляги — новым `HudFlasks` из `hud`, старые поля фляг и `UpdateFlasks()` убраны |
| `GAME_FEEL_IDEAS.md`, `AUDIO_DESIGN.md` | несколько | строки таблицы — версия с ✅; разделы 14а и 14б — оба |

Проверено в облаке только то, что можно: синтаксис всех изменённых `.cs` (tree-sitter), отсутствие маркеров
конфликтов, отсутствие продублированных `case` и полей после слияния. **Не проверено:** компиляция, тесты,
поведение.

Новые облачные ветки после этой даты (зоны 6–15, `GAME_FEEL` №2, 3, 9, 10, 15–21, комната-камера) в
`cloud/integration` не входят — их сливать поверх неё по той же схеме.

## 2. Локальная сессия — порядок

1. `git fetch`, `git checkout cloud/integration`, синхронизация копии (`AGENTS.md`, «Проверка»).
2. Компиляция в batchmode; ошибки чинить в `cloud/integration` (по одному коммиту на причину).
3. `ContentBuilder.Build` → `rsync` назад → откатить шум генератора.
4. `Scene*.Apply` для зон из текста (Гробница, Лес, Село, Столица), затем `SceneReactive.Apply`, `SceneMusic.Apply`.
5. `LevelCheck` по четырём текстам (урны `world-react`), затем по `marsh.txt` — Болота пока не подключены.
6. Весь EditMode, затем **полный PlayMode** (здесь он обязателен: 18 веток сразу).
7. Сборка Mac и `PerformanceProbe` с журналом подвисаний (§4).
8. Влить `cloud/integration` в `main` одним merge-коммитом, удалить слитые ветки.

## 3. План полного плейтеста

Проход **Гробница → Лес → Село → Столица** (всё, что построено), на геймпаде и клавиатуре, по
`VERTICAL_SLICE_QA.md`. Что ощутить по каждой ветке — по одной строке «да / нет / мешает»:

| Ветка | Что проверить руками |
| --- | --- |
| `movement`, `camera-look` | разворот в воздухе не «скользит»; прыжок из хвоста рывка; взгляд вверх-вниз не мешает бою |
| `combat-feel`, `hit-pitch`, `haptics` | удар весомый, но hit-stop не тормозит серию; тон серии не раздражает за 10 минут; вибрация в меру |
| `boss-death`, `hero-death` | замедление при смерти босса/героя не путается с паузой; блик за 0,2 с до удара успевает спасти |
| `mana-wisp`, `hud` | видно, откуда мана; полосы живые, но не отвлекают |
| `surfaces`, `world-react` | шаги различаются по зонам; урны — радость, а не помеха на пути; цепи и огни реагируют |
| `audio`, `music`, `ambience` | звук не утомляет за час; петли без стыков; туман не прячет врагов |
| `menus` | меню с живым фоном, фокус-пламя, настройки сохраняются |

Хронометраж: время прохождения каждой зоны, число смертей по месту (`GameProgressData.deaths`), где
игрок заблудился — в `VERTICAL_SLICE_QA.md` новым прогоном.

## 4. KI-012 — подвисания 0,3–0,7 с

В `cloud/hitch-probe` (входит в интеграцию) — `HitchLog`: каждый кадр ≥ 0,1 с с комнатой, загрузкой зоны,
приростом памяти текстур и драйвера, GC и временем маркеров рушия. Процедура:

1. **Development**-сборка Mac (маркеры только в ней): `-perfProbe "a.tsv"` три прохода подряд, затем
   `-perfProbe "b.tsv" -uploadBuffer 64 -uploadSlice 4` три прохода.
2. Читать `*-hitches.tsv`: время в `Shader.CreateGPUProgram`/`Shader.Parse` → гипотеза 1 (шейдеры/PSO);
   скачок `texture_mb_delta` и `Texture.AwakeFromLoad` → гипотеза 2 (кольцо загрузки); `zone_streaming = 1`
   → активация сцены зоны; ничего из этого → система (повторить без открытого Editor).
3. Лечение по итогу: (1) `GraphicsStateCollection` — записать в проходе пробы, прогревать на экране
   загрузки мира; (2) `asyncUploadBufferSize` 64–128 МБ в `QualitySettings` и сжатие текстур уровня (KI-011);
   (3) разнести активацию тяжёлых объектов зоны на несколько кадров.
4. Плейтест с `-hitchLog "play.tsv"`: замечает ли игрок оставшееся.
