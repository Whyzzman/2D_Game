# Мир на несколько сцен (п. 71 = п. 3 большого списка, 2026-09-28)

Решения пользователя: граница зон — **без шва** (сосед подгружается заранее, ни затемнения, ни
паузы; затемнение только у мандров и возрождения); **сцена на зону**; враги — **как раньше**
(побеждённые лежат до отдыха или смерти, боссы — навсегда).

## Сцены

| Сцена | Что в ней |
| --- | --- |
| `TombTrial` (сцена мира) | `Main Camera`, `Spawn`, `Player`, `Systems` (службы, HUD, `ZoneStreamer`), `Ambience/ZoneAir`, `Npcs/Services` |
| `Scenes/Zones/Zone_Tomb` | всё остальное Гробницы: земля, окружение, враги, алтари, находки, Страж, люди |
| `Scenes/Zones/Zone_Forest` | то же для Леса |

Координаты общие: зона — это участок мира, не отдельное пространство. У зоны в графе
`SceneName` = `TombTrial` (пространство, в нём `AreaAt`) и `ContentScene` — её сцена.
Имя `TombTrial` сохранено: его грузят меню, тесты и сохранения.

## Подгрузка — `ZoneStreamer`

- Держит загруженными текущую зону и соседей на `_neighbourDepth` переходов (1): соседство —
  связь графа между областями разных зон (`ZoneStreamingPlan`). Сейчас это обе зоны всегда.
- Старт: нужные зоны грузятся сразу; игрок заморожен (`Rigidbody2D.simulated`) до `Ready`,
  затем `PlayerRespawner` ставит его к сохранённому алтарю.
- Дальше — опрос раз в 0,2 с: зона по позиции игрока, догрузка (`LoadSceneAsync`), выгрузка
  лишних. `Prepare(zone)` — для мандров и возрождения под затемнением; пока он идёт, ничего
  не выгружается.
- `ZonesChanged` (статическое, кадр спустя после загрузки/выгрузки) — службы сцены мира
  заново находят объекты уровня (`ZoneObjects.New` / `All`): HUD, свет зон, камера (комнаты
  по земле), грейд, музыка, эмбиент, звук и фидбек боя, мандры, отладка.
- Побеждённые враги выгруженной зоны: `EnemyRegistry` помнит их по `EnemyController.SpawnKey`
  (сцена/имя/точка) до отдыха или смерти; вернувшийся враг лежит (`LieBeaten`) — без тела,
  добычи и опыта.
- Ссылки между сценами Unity не сохраняет: разделение их обрезает (список в логе), поле
  находит цель само (`FindAnyObjectByType` в `Awake`).

## Редактор — `WorldScenes`

- `Forgotten Kingdom/Scene/Open Whole World` — мир целиком для правки руками.
- `Split` — разрезать сцену мира как есть; `Rebuild(edit)` — после `BuildWithScenes`;
  `Edit(edit)` — собрать мир в одну сцену, выполнить правку, разрезать снова: так работают
  `SceneNpcs`, `SceneAmbience`, `SceneForestLook`, `SceneCharacterLight`.
- Раскладка по центру (рендеры + коллайдеры) — область графа под ним; `ZoneBackdrop` — по
  своему `_zoneId`; папка с содержимым разных зон делится, её путь повторяется в каждой сцене.
- Сцены зон — в Build Settings сразу после `TombTrial` (грузятся по имени).

## Ограничения

- Журнал «Люди» ищет размещения в загруженных сценах: персонаж из выгруженной зоны пропадёт из
  журнала. Сейчас обе зоны загружены всегда; с третьей зоной — брать место из данных.
- Выгрузка по-настоящему начнётся с третьей зоны (п. 2); сейчас она проверена тестом с
  глубиной 0.

Тесты: `WorldScenesDataTests` (2), `ZoneStreamingTests` (3); все PlayMode-тесты грузят мир
через `TestWorld.Load()`.
