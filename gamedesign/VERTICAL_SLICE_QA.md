# Vertical Slice — QA

Прогін 2026-09-22 (PHASE 23). Unity 6000.5.10f1, Windows build + headless.

**Як читати статуси.** Я не граю в гру. `PASS` тут означає **перевірено
автоматичним тестом і названо яким** — не «виглядає правильно». Все, що вимагає
людських очей або рук, стоїть як `NOT RUN`, а не як припущення.

| Статус | Значення |
| --- | --- |
| `PASS` | тримає названий автотест |
| `FAIL` | перевірено й не працює |
| `BLOCKED` | неможливо перевірити через відомий блокер (див. `KNOWN_ISSUES.md`) |
| `NOT RUN` | потребує ручної гри — я цього зробити не можу |
| `N/A` | у зрізі немає |

**Головне однією фразою:** зріз **не можна пройти як гру**. У сцені
`TombTrial` нуль `Canvas` і нуль `UIDocument` — інтерфейсу в Unity не існує.
Тому нема ні New Game, ні Continue, ні HUD, ні смерті з екраном. Код бою,
боса, збереження й музики — зелений і протестований; оболонки, яка робить із
нього гру, немає.
