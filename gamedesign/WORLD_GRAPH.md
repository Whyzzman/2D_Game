# Граф мира

План 15 зон (порядок, связи, способности) — `WORLD_DESIGN.md`; здесь — то, что уже в графе.

PHASE 25. Источник истины — `Assets/Game/Data/WorldGraph.asset`, его собирает
`ContentBuilder.BuildWorldGraph()` (`Assets/Game/Editor/ContentBuilderWorld.cs`).
Код: `Runtime/World/WorldGraph.cs`, `WorldGraphTypes.cs`, `WorldRules.cs`,
`WorldGraphValidator.cs`.

Граф заменил `ZoneRegistry` из PHASE 24: какой зоне принадлежит алтарь — теперь
вопрос к записи чекпойнта в том же графе, а не к отдельному списку.

## Что в графе

| Сущность | Поля | Зачем |
| --- | --- | --- |
| `ZoneDefinition` | id, имя, текст карточки, сцена, спавн по умолчанию, `IsImplemented`, тон карты | Регион. Недостроенная зона видна на карте только как запечатанная дорога. |
| `WorldAreaDefinition` | id, зона, имя, позиция и размер на карте, границы в сцене, `IsSecret`, `IsOptional`, правило открытия, связанная способность, иконка, босс | Комната. То, что рисует карта и записывает открытие. |
| `WorldConnection` | id, откуда, куда, направление, тип, двусторонняя ли, требуемые способность / прогресс / босс, шорткат и его постоянный id, из какой области открывается, «будущая» ли | Проход между комнатами. |
| `CheckpointDefinition` | id, имя, зона, область, `CanFastTravel` | База алтарей. Сцена хранит только id. |
| `AbilityDefinition` | id, имя, вид, босс-гарант | Что способность значит для мира. |

Связи и алтари у области **не дублируются**: граф индексирует их по области
(`ConnectionsOf`, `CheckpointsIn`). Все поиски идут через словари, построенные при
первом обращении, — пятнадцать зон стоят столько же, сколько две.

## Области

Границы старых зон — по X в мировых координатах; по Y основные комнаты занимают −8…18.
Зоны из текста (`LEVEL_TOOL.md`) берут области, связи и алтари из своего текста.
«Триггер» — открывается только своим `AreaDiscoveryTrigger`, а не попаданием в
границы (секретные карманы рядом с путём).

| AreaID | Имя | Зона | X | Вид |
| --- | --- | --- | --- | --- |
| Гробница — 27 комнат | | Гробница | −73,5…62,5, y −17…73 | из `Levels/tomb.txt` (п. 3 «Мира из 15 зон»): границы — прямоугольники комнат текста, тайные — по триггеру; старт `room_tomb_entrance` |
| Лес — 35 комнат | | Лес | 62,5…318, y −46…54 | из `Levels/forest.txt` (п. 4): первая `room_forest_root_tunnel` (вход из Гробницы), последняя `room_forest_far_gate` (выход на восток) |

Позиция на карте — мировой X × 0,1; основные комнаты в одном ряду (y = 0),
карманы выше. Карта не 1:1, но относительные положения честные.

## Прогрессия

```
New Game
  ↓
Забута Гробниця (вход → зала → проход → склеп → подступ)
  ↓
Страж Гробниці ── дверь из Гробницы открывается, мандри открываются
  ↓
Кореневий тунель → Зів'ялий Ліс (узлісся → дорога → карниз → арка → глибокий ліс → кладка → подступ → міст)
  ↓
Порожній Вартовий ── Подвійний стрибок, дверь на край леса
  ↓
Край лісу → запечатанная дорога на восток (будущая зона 3)
```

Петли возвращения:

- **Гробница по Подвійному стрибку.** После Вартового — назад пешком или мандрами к
  Вівтарю переходу, прыжок с уступа варты → Королівська костниця (Перстень Костниці).
- **Лес по Подвійному стрибку.** Драбина сокольника от подступа к вежі, Отруйний гай за кладкой
  (Зелене Серце), Терновий шлях из нижней галереи, Мисливський поміст с вершины вежи.
- **Шорткаты.** Мост над провалом Гробницы и решётка арки на королевской дороге —
  оба открываются с дальней стороны и делают обратный путь коротким и безопасным.

## Проверки

`WorldGraphValidator.Validate` — ContentBuilder пишет каждую проблему в лог, тест
`TheShippedGraphHasNoProblems` требует пустой отчёт:

- дубли id зон, областей, связей, алтарей, способностей;
- связь в несуществующую область, из области в неё же;
- неизвестная способность, босс без арены, шорткат без постоянного id или
  открываемый не со своего конца;
- алтарь в чужой зоне, в несуществующей области или в недостроенной зоне;
- область, найденная по позиции, без мировых границ (так ловится `Rect`, который
  не читается из JSON и тихо становится нулём);
- **основной путь**: каждая необязательная не-область достижима с одними
  гарантированными способностями и победами над боссами;
- боевой навык между двумя областями основного пути;
- отрезанная область, недостижимая даже со всеми способностями;
- **софтлок**: из каждой достижимой области снова достижим какой-то алтарь.

## Как добавить зону

1. Запись `ZoneDefinition` (новая сцена — в `_sceneName`).
2. Области с границами и позициями на карте, связь `ZoneTransition` из старой зоны.
3. Алтари в `_checkpoints`, те же id — на `Checkpoint` в сцене.
4. Если зона в другой сцене: реализовать ветку загрузки сцены в
   `PlayerRespawner.TravelRoutine` (сейчас такая мандрівка отклоняется как
   `NotInThisScene`, ничего не меняя).
5. Валидатор и тесты графа должны остаться зелёными.
