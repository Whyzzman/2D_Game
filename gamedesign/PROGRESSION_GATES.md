# Ворота прогрессии

PHASE 25. Код: `WorldGraph` (что куда ведёт), `WorldRules` (как читаются условия),
`PersistentDoor` (двери), `AbilityGate` (метка у физического препятствия),
`Shortcut` (постоянные шорткаты), `NonClimbableSurface` (гладкие грани).

## Реальные числа движения

Все высоты в этом документе — от **дискретного** прыжка, а не от формулы.
Мотор интегрирует на 50 Гц: скорость ставится, гравитация вычитается в том же шаге,
поэтому:

| Движение | Подъём ног |
| --- | --- |
| Прыжок (скорость 11, гравитация 30, у вершины ×0,5 при зажатом прыжке) | **1,97** (было 1,91 до 2026-09-26; по формуле v²/2g — 2,02) |
| Второй прыжок в вершине (9,5) | +1,46, итого **≈3,43** (было 3,32) |
| Бег по стене | 4 ед/с × 0,8 с ≈ 3,2 вдоль стены; с 2026-09-26 стена (скольжение, бег, прыжок от неё) возвращает второй прыжок и рывок в воздухе, как в Hollow Knight — только при открытом wall-run |
| Рывок / рывок в воздухе | горизонтально ~2,9, без подъёма |
| Дальность прыжка с разбега | ~4,9 на той же высоте (бег всегда 6,5, полёт 0,76 с; было ~4,2) |

Капсула игрока 0,8 × 1,6. Ступень основного пути — не выше **1,7** (запас 0,27).
Столбцы «без / с» в таблице ворот ниже посчитаны от старых 1,91 / 3,32; с зависанием
у вершины они выше на 0,06–0,11 — запас каждого из ворот от этого не исчезает.

## Виды способностей

`AbilityDefinition.Kind` в графе (`ContentBuilderWorld`):

| Способность | Вид | Где / гарант |
| --- | --- | --- |
| `dash` | TraversalProgression | с начала |
| `double-jump` | TraversalProgression | Порожній Вартовий (Лес) |
| `grapple` | TraversalProgression | Дзвонар (Село; с 2026-10-04, раньше — Король), только за кольца |
| `air-dash` | OptionalTraversal | лежит в Обваленому склепі (Гробница), взять можно не взять |
| `wall-run` | OptionalTraversal | лежит в Аркової галереї (Гробница) |
| `shadow-dash` | CombatSkill | ветка Тени в дереве умений |

Правило: **обязательные ворота** требуют только гарантированную способность после её босса или победу
над боссом; необязательные и боевые — никогда. Граф это доказывает
(`TheMainPathNeedsNoOptionalAbilityAndNoBuildChoice`), а бот с клавиатуры проходит основной путь туда и
обратно без способностей, кроме рывка (`TheWholeMainPathIsWalkableEastAndBackWithoutAnyAbility`). Для зон,
написанных текстом, то же проверяет `LevelCheck` (`LEVEL_TOOL.md`): комната `needs=X` недостижима без X.

Мир спрашивает только `HasAbility(id)` (`WorldState`, `GameProgress`). Дерево умений он не читает.

## Шорткаты

| Id | Где | Открывается | Что меняет |
| --- | --- | --- | --- |
| `shortcut_tomb_chain_gate` | решётка между Входом и Ланцюговою шахтою | лебёдкой со стороны шахты | короткий путь от входа к шахте и арене |
| `shortcut_forest_road_gate` | арка королевской дороги (Лес) | лебёдкой со стороны Поломаної арки | путь через арку на запад |
| `shortcut_capital_forest_road` | старая дорога Лес → Столица, x 318 | лебёдкой со стороны Столицы | обратный путь из Столицы в Лес (вход в Столицу — через Село) |

Состояние — `unlockedShortcuts` в сохранении; смерть, отдых и перезагрузка возвращают мир с открытым
шорткатом. Повторное потягивание ничего не делает. Карта: закрытый шорткат — пунктир, открытый — обычная
линия, в том же событии. Лифтов нет: мотор не умеет стоять на движущейся платформе.

## Проверенные обходы

| Попытка | Результат |
| --- | --- |
| Рывок / Тіньовий ривок в закрытую дверь Гробницы | упор в стену (`NoDashCarriesThePlayerThroughTheSealedTombDoor`) |
| Тіньовий удар по врагу за закрытой дверью | цель не находится: луч видимости режет стена |
| Перенос на незажжённый алтарь | `NotActivated` |
| Мандри из боя с боссом / в бою / мёртвым | `BossFight` / `InCombat` / `PlayerDead` |
| Комната `needs=X` без X | недостижима и щедрой моделью прыжка (`LevelCheck`) |

## Известные обходы

`LevelCheck` доказывает недостижимость комнаты `needs=X` без X только со способностями, с которыми в зону
входят (`abilities` в тексте). Обходы другими способностями — например, Реліквіарій вторым прыжком вместо
рывка в воздухе — не проверялись; все такие места необязательные (`KNOWN_ISSUES.md`, KI-009).
